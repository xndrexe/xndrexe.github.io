# Кейсы — боты, парсеры, отчёты по маркетплейсам

Одностраничный сайт: https://xndrexe.github.io/

Статика без сборки: `index.html`, `assets/style.css`, шрифт и картинки в
`assets/`. Публикуется через GitHub Pages из ветки `main`, корень.

## Как поменять почту

Почта для связи стоит в `index.html` в одном месте — строка под
комментарием `КОНТАКТ` (адрес в `href="mailto:…"` и в тексте кнопки).
Кнопки «Написать» и «Обсудить задачу» ведут к этому блоку.

## Картинки

Только настоящие выгрузки и отчёты демо-проектов на выдуманных данных:
имена, телефоны, магазины и документы придуманы для показа.

## Проверка

```bash
python3 -m http.server 8899 --bind 127.0.0.1
```

Сценарий проверки в браузере — `ui/scenarios/main.json`.
